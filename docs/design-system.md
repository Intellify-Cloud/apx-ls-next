GLASS STYLE
Use sparingly.
Glass surfaces should have:
- translucent background
- backdrop blur 10–12px
- subtle border
- soft shadow

Examples:
- Light glass: rgba(255,255,255,0.3)
- Subtle glass: rgba(255,255,255,0.1)
- Dark glass: rgba(15,23,42,0.9)
- Navy glass: rgba(12,26,55,0.6)

COMPONENTS

Navbar:
- Classic top navbar
- Sticky at top
- Height: 72px
- White/translucent background: rgba(255,255,255,0.8)
- Backdrop blur: 10px
- Bottom border: rgba(12,26,55,0.1)

Buttons:
Primary:

PAGE STRUCTURE
Use this homepage order:

1. Navbar
2. Hero
3. Social proof logos
4. Feature section
5. Benefits/use cases
6. Pricing
7. Testimonials
8. Blog/articles
9. FAQ
10. Final CTA
11. Footer

SECTION PATTERNS

Hero:
- Dark/navy or gradient background
- Two-column layout
- Left: eyebrow, H1, paragraph, CTA buttons
- Right: product visual/card/mockup
- H1 large and compact
- Body text spacious
- Use glass card for product visual

Social proof:
- Short centered line: “Trusted by…”
- Logo row
- Muted styling
- Keep quiet and minimal

Feature section with exactly 3 cards:
Use this layout:
- Centered section title
- Centered paragraph
- Then 2-column layout
- Left column: large copy block, image, or product visual
- Right column: 3 stacked cards
- End with centered closing copy
- Use generous vertical spacing

Feature/benefit section with more than 3 cards:
Use a responsive grid:
- 3 columns desktop
- 2 columns tablet
- 1 column mobile
- Cards should be consistent and scannable

Pricing:
- 3 pricing cards
- Highlight only one plan
- Featured card can be slightly raised
- Keep copy simple
- CTA per card
- Recommended badge on featured plan

Testimonials:
- 3 cards
- Quote, person name, role/company
- Calm, trustworthy design
- Do not overdecorate

Blog/articles:
- 3 article cards only on homepage
- Each card links to article page
- Include image/thumbnail area, category, title, excerpt, “Read article →”
- Add centered “View all articles” button below
- Keep this section editorial and calmer than features

FAQ:
- Two-column layout
- Left: FAQ heading and intro copy
- Right: FAQ list
- Each FAQ has heading, answer, bottom border
- Spacious and clean

Final CTA:
- Dark navy section
- Centered H2, paragraph, primary CTA, optional secondary CTA
- Should feel like emotional close

Footer:
- Dark navy background
- 4 columns desktop
- Column 1: brand + short description
- Columns 2–4: Product, Company, Resources
- Muted white text for links
- Keep useful, not decorative

RULES
- Do not use raw random colors; use the palette above.
- Do not use random spacing; use the spacing scale.
- Do not make everything glassy.
- Orange is for CTAs, links, emphasis, and active states.
- Titles should be compact.
- Body text should breathe.
- Exactly 3 cards should use the two-column storytelling pattern.
- More than 3 cards should use a grid.
- Keep one primary CTA per section.
- Prioritize readability over effects.
